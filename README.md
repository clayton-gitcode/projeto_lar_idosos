## 📝 Sobre o Projeto

Este projeto nasceu da necessidade de modernizar o controle de moradores e a organização administrativa de um **Lar de Idosos em Maria da Fé/MG**. Atuando como desenvolvedor voluntário, pude aplicar conhecimentos técnicos para resolver problemas reais de gestão, substituindo processos manuais por um sistema digital centralizado.

Esta foi minha **primeira experiência real de deploy em produção**, onde fui responsável por todo o ciclo: do desenvolvimento ao suporte direto ao usuário final.

---

## 🚀 Funcionalidades Principais

O sistema foi desenhado para ser intuitivo, atendendo às necessidades da equipe da instituição:

* **Gestão de Moradores:** Cadastro completo com histórico de saúde e documentos.
* **Controle Administrativo:** Organização de registros e dados da instituição.
* **Painel de Monitoramento:** Visualização rápida das informações críticas para o dia a dia.
* **Interface Responsiva:** Adaptado para uso em diferentes dispositivos.

## 🔧 Como Rodar o Projeto

Para testar ou contribuir com o projeto localmente:

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/clayton-gitcode/projeto_lar_idosos.git

    ```

2. **Configure o ambiente:**

    ```bash
    # Exemplo
    cp .env.example .env
    php artisan key:generate

    ```

3. **Inicie o servidor:**

    ```bash
    php artisan serve

    ```
